# 什么是 AI Skill？

## 从提示词到 Skill

在 Vibe Coding 中，你可能会发现自己经常写类似的提示词。如果能把这些常用指令**打包**成一个可复用的"技能包"，一键使用，这就是 **AI Skill**。

## Skill 的定义

**Skill（技能）** 是一种结构化的指令包，它为 AI 提供：专业知识、标准工作流程、可执行脚本、输出规范。

| 类比 | 说明 |
|------|------|
| 🎮 游戏技能 | 学会一个技能后，每次使用效果相同 |
| 📖 操作手册 | 标准流程，按步骤执行 |
| 🧰 工具箱 | 常用工具打包，需要时拿出来 |

## Skill vs 普通提示词

| 对比 | 普通提示词 | Skill |
|------|-----------|-------|
| 持久性 | 用完就没了 | 保存为文件，随时调用 |
| 复用性 | 每次重新写 | 一键使用 |
| 结构化 | 自由文本 | 有固定格式（SKILL.md） |
| 可分享 | 不方便 | 可以发布和安装 |
| 可扩展 | 只有文字 | 可以包含脚本和模板 |

## Skill 能做什么？

- **Excel 处理**：读取、分析、生成图表
- **PDF 处理**：提取文字、合并、拆分、OCR
- **PPT 制作**：创建演示文稿
- **代码审查**：按检查清单审查
- **自定义**：为你的工作流定制专属 Skill

## Skill 的结构

```text
my-skill/
├── SKILL.md          # 核心文件：技能定义
├── scripts/          # 可选：脚本文件
├── templates/        # 可选：模板文件
└── references/       # 可选：参考资料
```
