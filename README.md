# LetAiCode Vibe Coding 教程全集

LetAiCode 是一套面向中文用户的 **Vibe Coding 教程**，系统讲解如何使用 AI 编程工具把想法快速做成可运行、可发布、可迭代的项目。本教程覆盖 Vibe Coding 基础概念、AI 编程工具选择、Codex 教程、Claude Code 教程、提示词工程、代码审查与调试、Git 与 GitHub、项目发布、实战案例和 AI Skill。

如果你正在搜索 **Vibe Coding 入门教程**、**AI 编程教程**、**Codex 使用教程**、**Claude Code 中文教程**、**AI 辅助编程实战**、**提示词工程入门** 或 **零基础用 AI 做网站**，这份文档可以作为一条完整学习路线。

## 教程定位

这不是传统的编程语法教程，而是一份面向 AI 时代的实践型开发指南。核心目标是帮助你从“写代码”转向“指挥 AI”，用自然语言描述需求，让 AI 辅助完成网页、小工具、游戏、作品集网站等项目。

你将学到：

- 什么是 Vibe Coding，以及它和传统编程的区别
- 如何改变使用 AI 编程工具的思维方式
- 如何选择 Codex、Claude Code、Cursor、GitHub Copilot、Windsurf、v0、Bolt.new 等 AI 编程工具
- 如何写出清晰、结构化、可迭代的提示词
- 如何审查 AI 生成的代码、定位 bug、读懂浏览器控制台错误
- 如何用 MVP 思维拆解项目，避免一次性需求过大导致 AI 输出混乱
- 如何用 Git 和 GitHub 管理版本，保护 AI 编程过程中的每一次修改
- 如何把本地作品发布到线上，形成可展示的项目链接
- 如何使用和创建 AI Skill，让常用工作流变成可复用的技能包

## 为什么学习 Vibe Coding

Vibe Coding 代表了一种新的开发方式：你不再从语法、框架和 API 细节开始，而是从目标、需求、反馈和迭代开始。AI 负责生成代码，你负责定义方向、检查结果、反馈问题和持续推进。

这种方式尤其适合：

- 快速做原型
- 快速做个人项目
- 快速做静态网页和小工具
- 快速验证产品想法
- 快速学习网页开发和 AI 编程工作流

它并不意味着完全不需要理解代码，而是把学习重点从“如何手写每一行代码”转向“如何清晰表达需求、判断结果、管理项目和迭代产品”。
