# Codex 常见问题与解决方案

如果你还没完成安装或刚开始使用，建议先读 [Codex 介绍与安装指南](./01-codex-介绍与安装) 和 [Codex 快速入门](./02-codex-快速入门)。

## 安装相关

| 问题 | 解决方案 |
|------|---------|
| npm 权限错误 | 用 nvm 管理 Node.js |
| macOS 提示无法验证开发者 | 系统设置允许，或用 Homebrew 安装 |
| Windows 无法运行 | 使用 WSL |

## 认证相关

| 问题 | 解决方案 |
|------|---------|
| login 打不开浏览器 | 手动复制 URL 到浏览器 |
| API Key 认证失败 | 检查 Key 是否正确、余额是否充足 |
| 额度不足 | 等待刷新或切换到 o4-mini |

## 使用相关

| 问题 | 解决方案 |
|------|---------|
| 代码有 bug | 把错误信息粘贴给 Codex |
| 改了不该改的文件 | `/diff` 查看改动，用 Git 回退 |
| AI "忘记"之前的内容 | `/compact` 压缩或在 AGENTS.md 写明规范 |
| 只想看不想改 | `codex --sandbox read-only` |

## 网络相关

| 问题 | 解决方案 |
|------|---------|
| 访问慢/超时 | 设置代理或使用中转服务 |
| 搜索功能用不了 | 确认模型和订阅级别支持 |

## 快速自查清单

- [ ] Codex 版本最新？（`codex --version`）
- [ ] 认证正常？（重新 `codex login`）
- [ ] 网络通畅？
- [ ] 在正确目录？（`pwd`）
- [ ] 额度充足？（`/status`）
