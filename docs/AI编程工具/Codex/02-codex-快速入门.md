# Codex 快速入门

如果你还没装好环境，先看 [Codex 介绍与安装指南](./01-codex-介绍与安装)。

## 启动 Codex

```bash
mkdir my-first-project && cd my-first-project
codex
```

## 交互模式 vs 非交互模式

| 模式 | 命令 | 场景 |
|------|------|------|
| 交互模式 | `codex` | 日常开发，持续对话 |
| 单次任务 | `codex "你的指令"` | 快速执行一个任务 |
| exec 模式 | `codex exec "指令"` | 脚本/自动化 |
| 带图片 | `codex -i 截图.png "照着做"` | 从截图还原界面 |

## 基本操作演示

### 演示 1：创建网页
```text
帮我创建一个简单的网页，显示"Hello, Vibe Coding！"，
用大标题居中显示，背景是渐变蓝色。
```

### 演示 2：修改已有文件
```text
把标题文字改成白色，字体换成无衬线字体，
在标题下方加一段副标题"用 AI 创造一切"
```

### 演示 3：创建多文件项目
```text
帮我创建一个番茄钟网页应用。
把 HTML、CSS、JavaScript 分成三个独立文件。
功能：25 分钟倒计时，开始/暂停/重置按钮。
风格：圆形进度条，深色主题。
```

## 权限系统

| 级别 | 说明 | 适合场景 |
|------|------|---------|
| Read Only | 只能读取 | 代码审查 |
| Auto | 自动审批常规操作 | 日常开发（推荐） |
| Full Access | 全部自动通过 | 完全信任场景 |

## 实用斜杠命令

| 命令 | 功能 |
|------|------|
| `/model` | 切换 AI 模型 |
| `/diff` | 查看代码改动 |
| `/compact` | 压缩对话上下文 |
| `/plan` | 进入计划模式 |
| `/review` | 代码审查 |

## 会话管理

```bash
codex resume        # 恢复上一次会话
codex resume --last # 恢复最近的
codex sessions      # 查看所有历史
```

在交互模式中使用 `/fork` 可以克隆当前会话做实验。做完基础操作后，可以继续看 [Codex 进阶使用技巧](./03-codex-进阶使用技巧)；如果想直接练手，推荐去做 [从零做一个番茄钟应用](../../实战案例/01-从零做一个番茄钟应用)。
