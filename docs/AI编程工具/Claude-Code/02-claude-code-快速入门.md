# Claude Code 快速入门

如果你还没装好环境，先看 [Claude Code 介绍与安装指南](./01-claude-code-介绍与安装)。

## 启动 Claude Code

```bash
cd my-project
claude
```

> 💡 **重要**：一定要在项目目录中启动，这样 Claude 才能读取项目文件。

## 基本使用方式

| 方式 | 命令 | 场景 |
|------|------|------|
| 交互模式 | `claude` | 日常使用 |
| 带初始指令 | `claude "分析项目结构"` | 快速任务 |
| 单次查询 | `claude -p "用了什么技术栈？"` | 查询后退出 |
| 一键提交 | `claude commit` | 自动 Git 提交 |

## 实操演示

### 理解项目
```text
这个项目是做什么的？用了什么技术？
```

### 创建文件
```text
帮我创建一个简约风格的 404 页面。深色主题。
```

### 修改代码
```text
把首页的标题颜色改成渐变蓝紫色，字体大小改成 48px。
```

### 修 Bug
```text
控制台报了这个错误：
Uncaught TypeError: Cannot read properties of null
帮我看看是什么问题，然后修复它。
```

### Git 操作
```text
帮我看看改了哪些文件，然后用一条有意义的中文提交信息提交。
```

## 权限管理

Claude Code 的操作前需要审批。创建/修改文件会显示 diff 让你确认。

## 常用交互命令

| 命令 | 功能 |
|------|------|
| `/help` | 显示所有命令 |
| `/login` | 登录或切换账号 |
| `/resume` | 恢复上次对话 |
| `/clear` | 清除当前对话 |
| `/compact` | 压缩对话上下文 |
| `/model` | 切换模型 |

## 工作流最佳实践

1. **先理解，再动手**
2. **小步快跑**，每次只做一个功能
3. **善用 Git**，大改动前先创建分支
4. **用 /compact 管理上下文**
